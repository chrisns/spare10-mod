# The kit port (Codex design 8.2): every case of tests/kit and where its behaviour is tested on Codex.
# codex/test/kit-port.spec.ts reads this file. It fails when a kit case has no line, when a line names a
# kit case that does not exist, and when a target names no Codex case.
#
# A line is `<kit case> => <target> ; <target> ...`, under the `[<kit file>]` of its kit case. The kit
# case is the name of the test as its source writes it, a template with its ${...} parts. A target is:
#   <spec>|<text>   a Codex case: <text> is part of the name of exactly one test of codex/test/<spec>.spec.ts
#                   (for flow, of one case of tests/helpers/flow-cases.ts, which flow.spec.ts runs)
#   @<alias>        a target that an `@<alias> = <target>` line names
#   none:<reason>   the case tests Claude glue that has no Codex form. A `! <reason> = <text>` line says why.
#   gap:<text>      the behaviour exists on Codex, and no Codex case tests it yet. The spec pins their number.
# A case with a Codex target and a `none:` target is tested on Codex, except for the part that has no Codex form.
# A `* =>` line covers every case of its kit file.

! badge = Codex has no badge, so no badge row, pulse or redraw (design 1.3, impossible).
! carrier = A Codex hold is one open MCP call: no 10 s carrier, no hook budget, no re-arm (design 1.2).
! fork = Codex starts a broker for every thread: no engine forks, no agent list, no G8 (mapping 3).
! withdraw = A Codex form cannot be withdrawn: it stays until its turn changes (design 1.3, gap-3 C9).
! fill = Codex cannot put a dropped prompt back in the prompt box (design 1.3, impossible).
! dialog = The Codex form has two choices and no chip: no free text and no "Chat about this" (degraded 1).
! plugins = The hook of another plugin is its own Codex handler: spare10 never sees its calls or its context.
! env = Codex keeps consent and stops in state.json under one lock (3.7): no process env, no compare-and-set, no restamp and no env delay.
! clear = On Codex /clear starts a new session with a new id and a new state folder: nothing moves across it (degraded 7).
! resume = Codex has no in-session /resume to another conversation in one broker: a resumed thread keeps its session id.
! bg = Codex has no claude --bg sessions and no Claude daemon env (design 1.3).
! flag = Codex needs no function-hooks flag and has no question time limit: B28 and B29 have no Codex form (design 1.2).
! surfaces = Codex has no $.session.surfaces: attendance comes from the host kind and the session log (3.10).
! remote = Codex has no remote bridge surface.
! typing = The Codex ticker never reads the prompt box: it continues only an idle hosted thread (4.6, 7.3).
! ticker = The Codex root ticker is a Node timer through the Clock seam, started at the first root gate: no refused timer to heal and no watch timer (3.8).
! edges = Codex has no badge, so the ticker keeps no redraw edges (7.3).
! sessionEnd = Codex needs no session.end: a thread unload or an exit ends its broker and its ticker (design 1.2).
! legacy = No Codex version wrote a 0.1 or a 0.2 value: the Codex state starts with this version.
! b47 = One Codex session has no newer copy of spare10 that changes the spans: each broker takes the spans of its own settings (4.1).
! tellPre = On Codex the tell rides the PreToolUse answer as context, not a tool result (4.11).
! sweepAll = On Codex a stop interrupts every running turn of the session, subagents too (A18, 4.23).
! seedRead = The Claude module reads its $.store seed once per activation, and each Codex sense reads seed.json (3.6).
! seedWrite = On Codex each view writes seed.json from its own readings (3.6), and consent never goes there.
